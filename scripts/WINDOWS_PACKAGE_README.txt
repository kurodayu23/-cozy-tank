Cozy Tank Windows x64 运行包

解压整个文件夹后双击 CozyTank.exe。不要单独移动 EXE，保留 _internal。
无需安装 Python。需要 Windows 10/11 x64 和 Microsoft Edge WebView2 Runtime。
缺少 WebView2 时请从 https://developer.microsoft.com/microsoft-edge/webview2/ 下载 Evergreen Runtime。
方向键移动，空格/Enter 射击，ESC 暂停。
高分保存在 EXE 同目录，请解压到可写目录。界面字体在线加载，离线使用回退字体。
源码：https://github.com/kurodayu23/-cozy-tank
